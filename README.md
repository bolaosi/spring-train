# 春野 · 一幅正在生长的山林

这是一个无需构建、后端或外部素材的静态网页。它用 SVG 和原生 JavaScript 即时绘制并驱动春日山林，八个竖向滑杆会实时改变场景。

## 运行

- 下载项目后，双击 `index.html` 即可在现代浏览器中打开。
- 页面动画会自动开始；拖动右侧「场景参数」中的滑杆即可调整景观。按「恢复默认」可还原初始参数。
- 本项目没有音频，也不会从网络加载字体、图片或 JavaScript 库。

## GitHub Pages 部署

1. 在 GitHub 新建一个公开仓库，建议命名为 `spring-landscape`。
2. 将本目录中的所有文件上传到仓库根目录并推送到 `main` 分支。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，然后保存。
5. 等待 Pages 发布完成；部署地址会显示在 Pages 设置页。

`index.html` 位于仓库根目录，CSS 和 JavaScript 都使用相对路径，因此可直接从仓库根目录发布，也能放在 GitHub Pages 的项目子路径下。

## 项目文件

- `index.html`：全屏场景结构、内嵌 SVG 图层和参数面板。
- `favicon.svg`：浏览器标签中的叶片标记。
- `styles.css`：春季色板、玻璃面板、滑杆与响应式布局。
- `app.js`：固定种子森林轮廓、平滑动画、视差和参数映射。
- `DESIGN.md`：颜色、层级、动效、交互和响应式设计规范。

## 参数映射

| 参数 | 影响 |
|---|---|
| 行进速度 | 场景演化时间倍率 |
| 视角缩放 | 整幅景观的缩放 |
| 垂直位置 | 景观相机上下偏移 |
| 云层浮动 | 云团的缓慢位移幅度 |
| 山峦起伏 | 远山和近山的轮廓变化幅度 |
| 林冠繁茂 | 程序化树冠的数量和疏密 |
| 细节强度 | 林冠边缘与高光的细节变化 |
| 日光曝光 | 场景整体亮度 |

## 继续扩展

后续可加入更多季节色板、可保存的参数预设、导出场景配置，或增加低功耗静态模式；这些都不需要改变目前的静态部署方式。
