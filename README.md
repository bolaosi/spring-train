# 春野 · 摄像机穿行中的春日山林

一个免构建、免后端的全屏动态景观网页。画面以 Canvas 程序化绘制：远山、云、森林和桥梁按不同景深向左掠过；一列长编组蒸汽火车的车头固定在屏幕左侧约五分之一处并朝右，车厢从车头后方向左延伸出画面，近处树冠与云会随行进掠过并遮挡远景。项目内附循环背景音乐，并有随机间隔的程序化火车轰鸣。

## 运行

- 直接双击 `index.html`，或将项目文件放在任意静态网页托管服务上即可运行。
- 打开后自动播放；右侧「场景参数」滑杆实时改变景观。
- 背景音乐直接使用项目内的 `Outer Wilds.mp3`，循环播放，不引入远程音频或第三方库。
- 页面载入会尝试自动播放背景音乐，并在浏览器允许时同时启用火车轰鸣；若媒体自动播放被拦，第一次点击、触摸或键盘操作会启动声音。若音乐已自动播放、但浏览器单独限制 Web Audio，会提示交互以启用火车声。没有传统播放器控件。
- 火车轰鸣由 Web Audio API 实时合成，只在不固定的间隔短暂出现；音效期间会轻轻压低背景音乐，随后恢复。
- 不依赖图片素材、远程字体、第三方库或后端请求。
- 画布后带有内嵌 SVG 静态底图；如果本机预览没有执行 JavaScript，也不会只显示蓝色空景，面板会提示当前处于静态预览。动态动画与滑杆联动仍需要浏览器允许 JavaScript。

## 交互参数

| 参数 | 实际作用 |
| --- | --- |
| 行进速度 | 改变摄像机向左行进的速度，统一加快或放慢各景深层的视差、云和轮廓变化 |
| 视角缩放 | 改变取景比例，同时保持火车头部前端约在视口宽度 20% 处 |
| 垂直位置 | 上下移动景观取景 |
| 云朵起伏 | 改变云轮廓鼓起、收缩和尺寸呼吸的幅度 |
| 山峦起伏 | 改变远山和脊线的高度及缓慢起伏 |
| 林冠繁茂 | 改变树群间距、树冠大小、覆盖程度和空隙 |
| 细节强度 | 控制树冠边缘变化、叶片高光和柔焦程度；最低值更模糊，高值更丰富 |
| 日光曝光 | 调整整体亮度、对比度与色彩强度 |

## 视觉实现

- 蓝天约占画面上方五分之一，不绘制太阳；场景没有河流或水面。
- 森林以灰绿远景、青绿和嫩绿中景、深森林绿近景叠出多层春色，并加入低饱和黄绿色高光。
- 固定种子的连续林地、山脊和不规则云轮廓在 Canvas 中连续重绘；森林由宽窄不一的重叠冠块组成，云朵会发生局部鼓起、收缩、合并趋势，不是简单的静态贴图平移。
- 所有空间图层共享同一行进距离，再乘各自的景深系数。远处移动较慢，近处树冠掠过更快，形成横向穿行的视差。
- 桥梁是低对比度、分段绘制的细线悬索结构，穿过森林并会被较近的林冠按不同区段遮挡。火车是远景比例的长编组蒸汽列车，包含朝右的前置车头、四十节短车厢、车轮、烟囱和向左上方漂散的柔和烟团；车头前端固定在视口约 20% 处，车厢从车头后方向左延伸到画面外，近景树木和云会遮住车身的不同部分。
- 林冠边缘使用可调 Canvas 柔化。较低的「细节强度」呈现模糊色块，高值增加轮廓起伏和柔和高光。

## GitHub Pages 部署

1. 在 GitHub 创建公开仓库，建议命名为 `spring-landscape`。
2. 将本目录中的项目文件上传到仓库根目录并推送到 `main` 分支。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)` 并保存。

页面使用相对路径，放在 GitHub Pages 项目子路径下也能加载。仓库发布后可从 Pages 设置页取得公开网址。

本机 `file:///D:/...` 地址只能由本机浏览器读取；ChatGPT 的网页预览无法从你的 D 盘加载这个地址。要在 ChatGPT 或其他设备中打开，请先发布到 Pages，再使用生成的 `https://` 网址。

## 项目文件

- `index.html`：全屏画布、参数面板和可访问的滑杆标签。
- `styles.css`：玻璃拟态面板、竖向滑杆和桌面/手机布局。
- `app.js`：程序化山林、云、桥、火车、视差运动和参数映射。
- `DESIGN.md`：视觉构图、层级关系和动画逻辑。
- `favicon.svg`：浏览器标签图标。

页面使用一个 `requestAnimationFrame` 循环；隐藏标签页时暂停，尊重系统的减少动态效果设置。后续可增加季节色板、场景预设、更多桥段和可保存参数，而无需改变静态部署方式。
